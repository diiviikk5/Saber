Under the hood

From your drives to the shelf in four layers.

  1. 01

    Your drives

    Saber reads Steam's library folders and Epic's install manifests. Nothing is uploaded or synced.

  2. 02

    The scanner

    Every install becomes one entry in a plain JSON library you can read, back up or edit.

  3. 03

    The art

    Covers and banners come from Steam's local cache, or from any image you pick for a game.

  4. 04

    The shelf

    Drawn by the GPU, fitted to your window, and launched through the store that owns the game.

Does it replace Steam or Epic?
No. Saber launches games through the store that owns them, so achievements, cloud saves and friends keep working. It's the front door, not the house.
Do I need an account?
No. Saber never asks you to sign in. Your library is a JSON file on your own disk.
What about games from other places?
Add any executable with Ctrl N, then right-click it and choose “Change cover…” to give it art.
When can I download it?
Windows builds land with the first release. Watch the repository on GitHub to hear about it first.
